# 阅读工作台与本地词典

首页的“词典”模块复用已导入的柯林斯词库，可搜索英文单词或短语，显示完整义项、
中文释义与双语例句，支持常见词形还原和词条内跳转。点击“加入生词本”保存原形和
释义摘要；已收藏的词不会重复加入或重置掌握程度。“查看生词本”可直接进入复习。
词典页保留本次查询，返回后可继续查看；未收录或加载失败会显示提示，可修改或重新查询。

阅读页使用全屏工作台。顶部可返回书架或收起侧栏；左侧有“页面 / 目录 / 词典”。
点击英文单词会自动展开词典，保留当前阅读位置；拖动选择文字不会触发查词。
开启电子书“朗读”模式后，点击句子用于朗读；关闭朗读面板后恢复单词查询。
PDF 需要具备文字层，纯扫描件暂不支持点词。PDF 缩略图按可见区域按需生成。

查到词条后可以点击“加入生词本”，保存词条原形、简短释义、书名和原文词形。
重复收藏不会新增词条或重置掌握程度。生词本中的旧听写生词也使用同一柯林斯词库：
列表显示首条释义和一条例句，点击“查看全部注释”展开全部义项与双语例句，支持收起。
词库未收录或暂时不可用时保留原收藏释义；加载失败可点击“重新加载柯林斯”。
完整词条只在内存中缓存，不写进浏览器本地记录。生词本仍最多保留 40 个词。

基础练习的单词听写在答题或点击“看答案”后显示柯林斯首条释义和双语例句，
支持“查看全部注释 / 收起全部注释”。“播放例句”朗读当前显示的柯林斯英文例句。
听写与生词本共用注释缓存；加入生词本时优先保存已加载的柯林斯摘要。
词库未收录或加载失败时明确回退听写词表注释，不影响出题、判分和切题；失败可重试。

## 导入用户自己的 MDX 词典

安装依赖后，在项目目录运行：

```powershell
npm run dictionary:import -- "D:\BaiduNetdiskDownload\欧路词库文件\柯林斯双解学习词典"
```

也可以直接传入 `.mdx` 文件路径。导入器使用 `js-mdict` 6.x（MIT）读取词条，
生成 `public/dictionaries/collins/manifest.json` 和 256 个 JSON 分片。
页面按需读取分片，不依赖外部翻译 API。定义、中文翻译和例句均来自导入词库。
MDD 的原始脚本、样式和媒体不进入阅读页面，词条 HTML 会经过清理。

生成数据留在本机并被 Git 忽略。克隆仓库到新电脑后需要重新导入自己的词典。

## 构建与部署

```powershell
npm run build
```

Vite 会将 `public/dictionaries/collins/` 原样拷贝到 `dist/dictionaries/collins/`。
部署时发布完整 `dist/`，包括词典分片与 PDF 字体、解码器等资源。
仅推送代码不会把本机词库同步到服务器。

线上“选择书架文件夹”需要支持目录选择器的浏览器（例如 Chrome / Edge）和 HTTPS。
普通 HTTP 地址仍可使用“选一本书”和内置书；本机 localhost 开发不受 HTTP 限制。

## 验证

```powershell
npm test
npm run test:browser
```

自动化使用原创小型词条测试取词、词形变化、安全渲染和侧栏操作，
不需要访问用户的本地词库。实际词库可用 `read`、`book`、`child` 手动检查。
